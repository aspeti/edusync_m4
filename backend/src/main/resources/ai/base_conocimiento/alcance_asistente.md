# Alcance del asistente EduSync

EduSync es una plataforma académica multi-tenant (EdTech / GovTech). El asistente responde sobre los **procesos de la institución educativa**.

Cubre: gestiones escolares, cursos y paralelos, materias, profesores, estudiantes e inscripciones, periodos y secciones de evaluación, carga de calificaciones, cálculo de promedios, roles y el perfil de exportación SIE (Bolivia).

Las preguntas de datos (notas de un alumno, lista de un curso) las resuelven las tools del catálogo con el JWT del usuario. Las preguntas de «cómo funciona el proceso» las responde este corpus, citando el archivo fuente.
