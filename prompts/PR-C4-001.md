## 1. Anatomía del prompt

### 1.1 Role
```text
Eres un Senior Solution Architect especializado en el modelo C4 (Simon Brown)
y en la arquitectura de EduSync (SaaS B2B multitenant Bolivia, Java 21,
Spring Boot 3.3, PostgreSQL 15, Angular 17, AWS ECS Fargate).
```

### 1.2 Task
```text
Genera el diagrama C4 Level 1 (System Context) de EduSync en Mermaid,
mostrando los 3 actores humanos, el sistema principal y los 2 sistemas externos.
```

### 1.3 Context
```text
- Skill de referencia: .cursor/skills/c4-edusync/SKILL.md.
- Actores: Director (Jeanneth), Docente (Marcela), Secretaria (Wendy).
- Sistema principal: EduSync (plataforma SaaS B2B multitenant Bolivia).
- Sistemas externos: SIE Ministerio de Educacion (DA-05), AWS KMS (NFR-007).
- Archivo destino: docs/diagrams/c4_level1.mmd.
- Sin Unicode decorativo en labels (IG-10); relaciones con protocolo en 4to parámetro.
```

### 1.4 Reasoning
```text
1. Identificar todos los actores externos desde FSD + AGENTS.md.
2. Modelar solo lo visible desde fuera: actores, sistema, sistemas externos.
3. Escribir el bloque C4Context con Person(), System(), System_Ext() y Rel().
4. Verificar: sin Unicode, relaciones con protocolo.
```

### 1.5 Stop condition
```text
Detente cuando docs/diagrams/c4_level1.mmd exista y pase el checklist del skill.
```

### 1.6 Output
```text
docs/diagrams/c4_level1.mmd con bloque C4Context (< 35 líneas),
tabla de trazabilidad actores ↔ DA/NFR, checklist de validación.
```

## 2. Invariantes del prompt

- Sin caracteres Unicode decorativos en labels.
- Cada relación incluye protocolo en el 4to parámetro de `Rel()`.
- SIE referenciado como `System_Ext` con nota de cumplimiento Ley 070 (DA-05).

## 3. Failure modes declarados

| Código | Descripción | Acción del consumidor |
|--------|-------------|------------------------|
| `E_UNICODE_EN_LABELS` | Em-dash u otros Unicode en labels | Reemplazar con ASCII |
| `E_PROTOCOLO_FALTANTE` | `Rel()` sin 4to parámetro | Añadir protocolo |
| `E_ACTOR_OMITIDO` | Actor del FSD no aparece en el diagrama | Añadir |

## 4. Guardrails

- MUST: validar que los 3 actores y 2 sistemas externos están presentes.
- MUST NOT: usar caracteres Unicode en labels del `.mmd`.

## 6. Pruebas del prompt

### 6.1 Caso feliz
- **Input**: skill c4-edusync + FSD completo + AGENTS.md v0.2.
- **Output esperado**: C4Context con 3 actores, 1 sistema, 2 sistemas externos, todas las relaciones con protocolo.

### 6.2 Caso borde
- **Input**: FSD sin mención explícita de AWS KMS.
- **Output esperado**: el agente infiere AWS KMS de NFR-007 (cifrado en tránsito y en reposo).

### 6.3 Caso adversarial
- **Input**: propuesta de usar `→` (flecha Unicode) en el label de una relación.
- **Comportamiento esperado**: rechazado con `E_UNICODE_EN_LABELS`; se usa `->` ASCII.
