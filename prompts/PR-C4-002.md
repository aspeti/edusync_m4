## 1. Anatomía del prompt

### 1.1 Role
```text
Eres un Senior Solution Architect especializado en el modelo C4 y en la
arquitectura hexagonal de EduSync (7 contenedores, DA-01..DA-05).
```

### 1.2 Task
```text
Genera el diagrama C4 Level 2 (Containers) de EduSync en Mermaid,
mostrando los 7 contenedores internos con sus tecnologías y las
relaciones con sistemas externos.
```

### 1.3 Context
```text
- Skill de referencia: .cursor/skills/c4-edusync/SKILL.md.
- Contenedores: Angular SPA, API Gateway, Domain Layer, PostgreSQL 15,
  Event Bus, SIE Adapter, Scheduler.
- Sistemas externos: SIE Ministerio, AWS KMS.
- Archivo destino: docs/diagrams/c4_level2.mmd.
- Stack: Java 21 / Spring Boot 3.3 / Angular 17 / PostgreSQL 15 / AWS ECS Fargate.
- Sin Unicode en labels (IG-10); FSD-UC + DA en descripciones.
```

### 1.4 Reasoning
```text
1. Mapear cada FSD-UC a su contenedor principal.
2. Construir el bloque C4Container con System_Boundary, Container(), ContainerDb().
3. Definir todas las relaciones con protocolo y DA/BR citados.
4. Validar: 7 contenedores, trazabilidad FSD-UC completa, sin Unicode.
```

### 1.5 Stop condition
```text
Detente cuando docs/diagrams/c4_level2.mmd exista, pase el checklist del skill,
y la tabla de trazabilidad FSD-UC ↔ contenedor esté completa.
```

### 1.6 Output
```text
docs/diagrams/c4_level2.mmd con bloque C4Container (< 80 líneas),
tabla de trazabilidad FSD-UC ↔ contenedor con DA/BR aplicados.
```

## 2. Invariantes del prompt

- Sin caracteres Unicode decorativos en labels.
- Cada contenedor cita al menos un FSD-UC o DA que lo justifica.
- Domain Layer sin dependencias de Spring/JPA en la descripción (DA-02).

## 3. Failure modes declarados

| Código | Descripción | Acción del consumidor |
|--------|-------------|------------------------|
| `E_CONTENEDOR_SIN_UC` | Contenedor sin FSD-UC asignado | Rechazar hasta completar |
| `E_RLS_NO_DECLARADO` | PostgreSQL sin mención de RLS | Añadir [DA-01] en descripción |
| `E_UNICODE_EN_LABELS` | Caracteres especiales | Reemplazar con ASCII |

## 4. Guardrails

- MUST: validar que los 7 contenedores están presentes y tienen FSD-UC asignado.
- MUST NOT: declarar dependencias de Spring/JPA en el Domain Layer container.

## 6. Pruebas del prompt

### 6.1 Caso feliz
- **Input**: C4 L1 completo + LFSD con estructura de paquetes.
- **Output esperado**: C4Container con 7 contenedores, todas las relaciones con protocolo y DA citados.

### 6.2 Caso borde
- **Input**: LFSD sin documentar explícitamente el Event Bus como contenedor.
- **Output esperado**: el agente infiere el Event Bus de los Spring Events y lo documenta con `[DA-04]`.

### 6.3 Caso adversarial
- **Input**: propuesta de marcar Domain Layer con `technology: Spring Boot`.
- **Comportamiento esperado**: rechazado; Domain Layer es puro Java (DA-02), Spring está en Infrastructure.
