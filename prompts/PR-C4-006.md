## 1. Anatomía del prompt

### 1.1 Role
```text
Eres un Senior Cloud Architect especializado en AWS, C4 Deployment y sistemas SaaS multitenant Java/Spring.
```

### 1.2 Task
```text
Genera el C4 Deployment AWS de EduSync, con .mmd y .md espejo, mapeando CloudFront/S3, ALB/WAF, ECS Fargate, RDS Multi-AZ, SQS FIFO/DLQ, KMS, Secrets Manager, CloudWatch, CloudTrail y Terraform.
```

### 1.3 Context
```text
Fuentes: ADR-0006, DTI §8, ADR-0001, ADR-0004, ADR-0005.
Destino: docs/diagrams/deployment_aws.mmd + .md.
Objetivo: criterio 2 y criterio 7 de la defensa final.
```

### 1.4 Reasoning
```text
1. Mapear cada componente EduSync a servicio AWS con justificación.
2. Mantener monolito modular v1.0 sobre ECS Fargate; SQS como evolución v1.1+.
3. Modelar seguridad: TLS, WAF, KMS, Secrets Manager y CloudTrail.
4. Modelar observabilidad: CloudWatch Logs/Metrics/Synthetics.
```

### 1.5 Stop condition
```text
Detente cuando .mmd y .md existan, C4Deployment sea válido, y la tabla AWS -> responsabilidad cubra todos los servicios de ADR-0006.
```

### 1.6 Output
```text
docs/diagrams/deployment_aws.mmd
docs/diagrams/deployment_aws.md
```

## 2. Invariantes del prompt

- No afirmar que `infra/` ya existe.
- No convertir EduSync v1.0 en microservicios productivos.
- RDS PostgreSQL 15 mantiene RLS.
- `.mmd` y `.md` se versionan juntos (IG-09).
- Sin Unicode decorativo en labels (IG-10).

## 3. Failure modes declarados

| Código | Descripción | Acción |
|--------|-------------|--------|
| `E_INFRA_INVENTED` | Se afirma que Terraform/infra ya existe sin evidencia | STOP |
| `E_MICROSERVICE_DRIFT` | El deployment muestra microservicios productivos v1.0 | STOP |
| `E_AWS_MAPPING_GAP` | Servicio AWS de ADR-0006 sin nodo/justificación | STOP |

## 4. Guardrails

- MUST: cubrir CloudFront/S3, ALB/WAF, ECS, RDS, SQS, KMS, Secrets Manager, CloudWatch, CloudTrail y Terraform.
- MUST NOT: inventar métricas ejecutadas de AWS.
